# ระบบติดตามความคืบหน้าโครงการ (Google Apps Script)

เว็บแอปสำหรับบันทึกและติดตาม Progress ของแต่ละโครงการ **รายเดือน** โดยเก็บข้อมูลลง Google Sheets โดยตรง เหมาะสำหรับใช้ "เบิก" (ดึง/สรุป) ความคืบหน้าของแต่ละโครงการเพื่อรายงานผู้บริหารหรือทีมงาน

## โครงสร้างไฟล์

- `code.gs` — โค้ดฝั่งเซิร์ฟเวอร์ (อ่าน/เขียน Google Sheets, จัดการโครงการและบันทึกความคืบหน้า)
- `index.html` — หน้าเว็บฝั่งผู้ใช้ (ธีมสีไล่โทนแบบ Instagram, ฟอนต์ Kanit) แบ่งเป็น 4 แท็บ: ภาพรวม / บันทึกความคืบหน้า / โครงการ / ประวัติ

## วิธีติดตั้ง

1. เปิด Google Sheet ที่ต้องการใช้เก็บข้อมูล (หรือสร้างใหม่)
2. ไปที่เมนู **ส่วนขยาย (Extensions) > Apps Script**
3. ลบโค้ดเริ่มต้นในไฟล์ `Code.gs` แล้ววางเนื้อหาจาก `code.gs` ในโปรเจกต์นี้แทน
4. สร้างไฟล์ HTML ใหม่ในโปรเจกต์ Apps Script ตั้งชื่อว่า `index` (ไม่ต้องใส่ `.html`) แล้ววางเนื้อหาจาก `index.html`
5. กด **Deploy > New deployment**
   - Select type: **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone** (หรือปรับตามนโยบายองค์กร)
6. กด Deploy แล้วเปิดลิงก์ Web app ที่ได้เพื่อใช้งาน

เมื่อรันครั้งแรก ระบบจะสร้างชีท **"Projects"** และ **"Progress"** พร้อมหัวตารางให้อัตโนมัติ หากยังไม่มีอยู่ในไฟล์ Google Sheets

## โครงสร้างข้อมูลในชีท

### ชีท "Projects" (รายชื่อโครงการ)

| ProjectID | ProjectName | Owner | StartDate | Status | Description | CreatedAt |
|---|---|---|---|---|---|---|

สถานะโครงการ: `กำลังดำเนินการ`, `เสร็จสิ้น`, `ระงับชั่วคราว`, `ยกเลิก` (แก้ไขได้ในตัวแปร `PROJECT_STATUSES` ใน `code.gs`)

### ชีท "Progress" (บันทึกความคืบหน้ารายเดือน)

| ID | ProjectID | ProjectName | Month | Progress | Status | Notes | UpdatedBy | UpdatedAt |
|---|---|---|---|---|---|---|---|---|

- **Month** เก็บในรูปแบบ `YYYY-MM` — หนึ่งโครงการบันทึกได้ **1 แถวต่อ 1 เดือน** ถ้าบันทึกซ้ำเดือนเดิม ระบบจะ**อัปเดตทับ**แถวเดิมแทนการเพิ่มแถวใหม่ (upsert)
- สถานะความคืบหน้า: `ตามแผน`, `ล่าช้า`, `มีความเสี่ยง`, `เสร็จสมบูรณ์` (แก้ไขได้ในตัวแปร `PROGRESS_STATUSES` ใน `code.gs`)

## ฟีเจอร์หลัก

### 1. ภาพรวม (Dashboard)
- เลือกเดือนที่ต้องการดู แสดงการ์ดสรุป: จำนวนโครงการทั้งหมด, ความคืบหน้าเฉลี่ย, จำนวนที่ล่าช้า/มีความเสี่ยง, จำนวนที่เสร็จสมบูรณ์, จำนวนที่ยังไม่รายงานเดือนนั้น
- แสดงการ์ดของแต่ละโครงการพร้อม progress bar, badge สถานะ และกราฟเส้นแนวโน้ม (sparkline) ของ 6 เดือนล่าสุด
- ถ้าโครงการยังไม่มีการรายงานของเดือนที่เลือก ระบบจะ **ใช้ค่าล่าสุดก่อนหน้า** แทนโดยอัตโนมัติ

### 2. บันทึกความคืบหน้า
- ฟอร์มเลือกโครงการ + เดือน + % ความคืบหน้า (มี slider + ช่องกรอกตัวเลขซิงก์กัน) + สถานะ + หมายเหตุ + ผู้บันทึก
- บันทึกซ้ำเดือนเดิมของโครงการเดิม = แก้ไขข้อมูลเดือนนั้น ไม่สร้างแถวซ้ำ

### 3. โครงการ
- เพิ่มโครงการใหม่ (กันชื่อซ้ำ) และแก้ไขข้อมูลโครงการที่มีอยู่ (ชื่อ/ผู้รับผิดชอบ/สถานะ/รายละเอียด) — ถ้าเปลี่ยนชื่อโครงการ ระบบจะอัปเดตชื่อในประวัติ Progress ที่เกี่ยวข้องให้อัตโนมัติ

### 4. ประวัติ
- ตารางบันทึกความคืบหน้าทั้งหมด กรองตามโครงการ/ช่วงเดือนได้ พร้อมปุ่มลบรายการ (กรณีบันทึกผิด)
- ปุ่ม **"⬇ ส่งออก CSV"** เพื่อดึง (เบิก) ข้อมูล Progress ตามตัวกรองปัจจุบันออกมาเป็นไฟล์ CSV เปิดต่อใน Excel/Google Sheets ได้ทันที

## หมายเหตุ

- ระบบใช้ `LockService` ป้องกัน race condition ตอนเขียนข้อมูล (เพิ่ม/แก้ไขโครงการ, บันทึก/ลบ progress)
- ทุกครั้งที่บันทึก/แก้ไข/ลบข้อมูล หน้าเว็บจะเด้ง popup แจ้งผลกลางจอ (สำเร็จ/ผิดพลาด/ยืนยันก่อนลบ)
- ไม่มีระบบยืนยันตัวตนผู้ใช้ในตัว หากต้องการจำกัดสิทธิ์การเข้าถึง ให้ปรับ "Who has access" ตอน Deploy หรือเพิ่ม logic ตรวจสอบอีเมลผู้ใช้ (`Session.getActiveUser().getEmail()`) ใน `code.gs` เพิ่มเติม
